隱私權政策

應用程式：郵輪查房小幫手（com.ezlin.cruisewatch）
最後更新：2026 年 9 月 1 日

本應用程式為個人開發之非官方工具，與星夢郵輪（Star Dream Cruises）及其母公司無任何 隸屬、合作或授權關係。本政策說明本應用程式如何處理您的資料。

一、我們不經營伺服器

本應用程式沒有任何屬於開發者的後端伺服器。您的帳號、密碼、搜尋內容 都不會傳送到開發者持有或控制的主機。App 只會連線到兩個對象：星夢郵輪官方伺服器， 以及 Google 的 Firebase 服務（用於當機回報與匿名使用統計，詳見第四節）。

二、帳號與登入憑證

密碼

登入時，App 會在內建瀏覽器中開啟星夢郵輪官方登入網頁 （sdr.stardreamcruises.com）。您的會員編號與密碼是直接輸入至官方網頁並 傳送給官方伺服器。本應用程式不會儲存您的密碼，也不會將密碼傳送給 開發者或任何第三方。

存取權杖（Token）

登入成功後，App 會取得官方核發的存取權杖與更新權杖，並僅儲存在您裝置本機 的私有應用程式空間中（Android 私有 SharedPreferences，其他應用程式無法讀取）。 這些權杖僅用於代表您向星夢郵輪官方 API 查詢資料。

本應用程式已停用 Android 雲端備份（allowBackup="false"），權杖不會被 備份到您的 Google 帳戶。

三、儲存在您裝置上的資料

以下資料僅存在於您的裝置本機，不會傳送給開發者：

  • 存取權杖與更新權杖、權杖核發時間
  • 會員姓名、會員卡別、客房積分數量與有效期限、獎賞數量
  • 最近數筆搜尋結果與搜尋時間
  • 行程名稱、出發日期、碼頭排班、您的預訂紀錄等查詢快取
  • 您選擇的出發港口、人數、日期篩選範圍
  • 是否已閱讀免責聲明

在 App 內執行「登出」會清除上述所有登入狀態與快取；解除安裝本應用程式則會刪除 全部本機資料。

四、傳送給第三方的資料

星夢郵輪官方伺服器

查詢客房空位、行程、出發日期、客房積分、您的預訂等功能，皆由 App 直接連線至星夢 郵輪官方 API（backend-prd.b2m.stardreamcruises.com）完成。這些請求的 內容與回應開發者無從得知。您與星夢郵輪之間的資料處理適用該公司自身的隱私權政策。

Google Firebase

本應用程式使用下列 Firebase 服務：

  • Crashlytics（當機與錯誤回報）：當程式發生當機或例外時，會傳送 錯誤堆疊與診斷資訊。為了重現問題，報告中會包含操作足跡，其中可能含有：您當下 選擇的出發港口與人數、搜尋到的客房日期與房型名稱、以及您已預訂的航班 日期與房型。報告不含您的姓名、會員編號、密碼或權杖。
  • Analytics（使用統計）：會傳送您目前的客房積分數量（作為統計事件 與使用者屬性），以及 Firebase Analytics 自動收集的資訊，包含應用程式執行個體 識別碼、裝置型號、作業系統版本、依 IP 位址推估的概略地區與工作階段資料。
  • Cloud Messaging（推播通知）：用於接收開發者發送的全體公告。 裝置的推播識別碼由 Google 管理，本應用程式不會上傳或儲存該識別碼， 也無法對特定使用者單獨推播。

上述資料的處理適用 Firebase 隱私權說明 與 Google 隱私權政策。

五、我們不做的事

  • 不販售您的個人資料，也不為廣告或行銷目的分享資料
  • 不整合任何廣告聯播網；已明確移除廣告識別碼（AD_ID）權限
  • 不收集精確位置、通訊錄、簡訊、通話紀錄、相片、麥克風或相機資料
  • 不在背景持續執行或追蹤您的使用行為

六、權限說明

  • 網際網路：連線至星夢郵輪官方 API 與 Firebase
  • 通知：在搜尋到可預訂客房、或登入失效時提醒您

七、資料刪除

您可以隨時在 App 內點選「登出」清除本機的登入憑證與快取，或直接解除安裝本應用程式 以刪除所有本機資料。

若您希望刪除已傳送至 Firebase 的當機報告或統計資料，請透過下方電子郵件與開發者聯繫， 我們將在合理期間內處理。請注意，本應用程式無法刪除星夢郵輪官方持有的您的帳號資料， 該部分請直接洽詢星夢郵輪。

八、兒童隱私

本應用程式並非以未滿 13 歲之兒童為對象，也不會刻意收集兒童的個人資料。

九、政策變更

本政策如有修訂，將更新本頁最上方的「最後更新」日期。重大變更會透過應用程式內的 公告通知使用者。
