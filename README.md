# 郵輪查房小幫手 — 隱私權政策

這個 repo 只有一個用途：以 GitHub Pages 公開託管
Android 應用程式「郵輪查房小幫手」（`com.ezlin.cruisewatch`）的隱私權政策，
供 Google Play Console 填寫「隱私權政策網址」使用。

公開網址：<https://eztrisoaring.github.io/cruisewatch-privacy/>

- `index.html` — 政策全文（自包含單檔，CSS 內嵌，支援深色模式與手機版面）
- `.nojekyll` — 純靜態 HTML，關閉 GitHub Pages 的 Jekyll 前處理

政策內容的正本與 App 原始碼一起維護，修改後需同步更新此處，
並記得一併更新政策內文最上方的「最後更新」日期。
